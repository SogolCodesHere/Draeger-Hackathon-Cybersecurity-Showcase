# 🧠 Agile AI Coach — Draeger Hackathon 2025  

An AI-supported web application designed to **assist Agile Coaches** in managing and improving team collaboration through intelligent feedback, speech transcription, and chatbot interactions.  

Developed during the **Draeger Hackathon 2025** by Team [your team name].  

---

## 🚀 Features  

- 🎙️ **Speech-to-Text Integration** — Record voice notes using the **Azure Cognitive Services Speech SDK**  
- 💬 **AI Chat Support** — Receive insights and suggestions based on agile coaching principles  
- 🧩 **User Management** — Coaches and teams can log in and manage sessions  
- 🗄️ **MongoDB Database** — Data is stored securely using a local MongoDB container via Docker  
- 🌐 **Flask Backend API** — RESTful endpoints connecting the frontend with AI services  
- 🧱 **Dockerized Setup** — Simplified local development with `docker-compose`
